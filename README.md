# Ritaban Datta — Portfolio

A responsive, static personal portfolio website built with HTML, CSS and a tiny JavaScript file. It is ready to publish using GitHub Pages.

## Preview locally
Open `index.html` in your browser.

## Publish with GitHub Pages
1. Create a GitHub repository named `your-username.github.io` (or any repository name).
2. Upload `index.html`, `styles.css`, `script.js` and this README to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish your site. Your URL will be shown in the Pages settings.

For a user-site repository named `your-username.github.io`, the address is `https://your-username.github.io/`. For another repository name, it is usually `https://your-username.github.io/repository-name/`.

## Personalise before publishing
- Replace the LinkedIn URL in `index.html` with your actual profile URL.
- Add a downloadable CV by placing a PDF (for example, `Ritaban_Datta_CV.pdf`) in the repository and adding a link to it.
- Review every experience statement and add only metrics you can substantiate publicly.
- Add detailed case studies only after removing employer/client confidential information.
- Optional: replace the generic project summaries with approved, specific examples and outcomes.
